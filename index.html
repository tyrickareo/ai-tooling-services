实测记录

这套环境里实际跑通过的三条记录，不是客户案例。

  1. 本地隔离安装 Agent Reach 1.6.1：用独立 venv + HOME 重定向把配置、缓存、工具、浏览器数据全部留在项目目录；提供 cmd 与 sh 两个启动器，未写入全局。
  2. Windows 代理排障：requests/urllib 不读注册表代理，导致网页与 API 请求全部超时；启动器自动读取系统代理后恢复。
  3. opencli / X 双策略排障：读操作走 cookie + GraphQL 接口，写操作走页面 DOM 点击；headless 与独立浏览器 profile 分别造成登录态与搜索失效，切回日常浏览器会话后恢复。
